Configuración de Inteligencia Artificial

Configura las credenciales de la API de Google Gemini y los modelos generativos para el banco de preguntas, tutor socrático y simulaciones.

Parámetros de Google Gemini

Los ajustes configurados aquí se aplicarán a todas las funciones de IA de la plataforma sin requerir reiniciar el servidor.

Si experimentas el mensaje de "high demand" en Google, selecciona Gemini 2.0 Flash o Gemini 1.5 Flash-8B.

Guía para obtener y usar la API

Para que la generación con IA funcione en producción:

  1. Accede a Google AI Studio (API Keys).
  2. Genera una nueva Gemini API Key (comienza típicamente con caracteres como AIzaSy... o similar).
  3. Pega tu clave en el campo Clave de API de la izquierda y haz clic en Probar conexión.
  4. Una vez confirmada la respuesta en verde, pulsa Guardar configuración.
💡
Configuración en archivo .env: También puedes definirla en el archivo de entorno en la raíz del proyecto: 
IA_PROVEEDOR=gemini
IA_MODELO=gemini-1.5-flash
IA_CLAVE=tu_clave_aqui
